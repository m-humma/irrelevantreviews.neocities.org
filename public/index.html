About

Hello! This is a tiny website I use to publish my own game reviews online. I'm not a professional by any means, and I only write these for fun, so don't expect too much. Obviously, every review I write is subjective, so don't be too peeved if you don't agree with a review. Most of the games I play are pretty old, hence the name "irrelevant", but I'll still try to play some newer ones... maybe. I just write about what I care about. See my game library on Backloggd! I also have a RetroAchievements account. If you wanna know more about me, visit my 100 Questions for Webmasters. This website is also proudly open-source! See the code on GitHub.

Ratings System

# Rating Description
1-2 Horrendous Absolutely abyssmal. Do not play unless you want to be miserable.
3-4 Bad Still bad, but it's almost enjoyable. Just almost. Play at risk.
5 Mediocre It's okay. It has flaws, but it's still enjoyable. Might be a bit of a slog, though.
6-7 Good Decent game, I would recommend, though they're not the first to come to mind.
8-9 Amazing Amazing game. You will have an amazing time if you play. Play if you're interested.
10 Perfect Absolute must-play. Some of my favourite games. Play them now!
